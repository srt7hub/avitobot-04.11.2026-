# Бриф для нового клиента (Google Forms) → системный промпт бота

Цель: собрать у клиента посуточной аренды данные, из которых ИИ соберёт его
индивидуальную инструкцию для бота (`customPrompt`). Базовый промпт (правила
Авито, формат ответа, механика) — постоянный, в форме НЕ спрашивается.

Конвейер: **Google Forms → ответы → ChatGPT (промпт сборки ниже) → customPrompt → вставить в ops → поле «Доп. инструкция клиента»**.

---

## Как пользоваться этим файлом

1. Создай Google-форму, перенеси вопросы из раздела **A** (тип вопроса указан).
2. Поля из раздела **B** (код двери, wifi, заезд) — заводятся в карточке объекта
   (ops → Properties или кабинет клиента), НЕ в текст промпта. В форме их собираем
   для удобства, но вносим в отдельные поля `Property`.
3. Получив ответы, бери раздел **C** (промпт сборки) + ответы клиента → отдай ИИ →
   получишь готовый `customPrompt`.

Условные обозначения типа вопроса:
- **[текст]** — короткий ответ; **[абзац]** — длинный ответ;
- **[выбор]** — один из вариантов; **[выбор+]** — несколько; **[шкала/да-нет]**.

---

## A. Вопросы для customPrompt (бизнес-логика бота)

### Раздел 1. О бизнесе и тоне общения
1. Как зовут вашего бота-менеджера? (имя, которое увидит гость) — **[текст]**
2. В каком городе/районе работаете? — **[текст]**
3. Как бот должен общаться с гостями? — **[выбор]**
   - Дружелюбно и тепло, на «вы»
   - Деловито и кратко, на «вы»
   - Неформально, на «ты»
   - Свой вариант
4. Есть ли слова/тон, которых бот точно НЕ должен использовать? — **[абзац, необязательно]**

### Раздел 2. Бронирование и оплата
5. Что бот отвечает, когда гость хочет забронировать? (если нет своего — оставьте
   пустым, подставим стандарт «предоплата через Авито») — **[абзац, необязательно]**
6. Берёте ли предоплату? — **[выбор]** Да, всю сумму / Да, часть / Нет

### Раздел 3. Отмена и возврат (важно — у всех по-разному!)
7. За сколько дней до заезда отмена бесплатная? — **[выбор]**
   - 7 дней / 3 дня / 1 день / Бесплатной отмены нет / Свой вариант
8. Что происходит при поздней отмене (меньше срока выше)? — **[выбор]**
   - Предоплата не возвращается
   - Возвращается частично
   - Возвращается полностью
   - Свой вариант
9. За сколько дней деньги возвращаются гостю? — **[текст]** (например: «5 рабочих дней»)

### Раздел 4. Цена и торг
10. Как бот реагирует на просьбу о скидке? — **[выбор]**
    - Скидку не даём
    - Скидка за длительное проживание (от N ночей)
    - Скидка на следующее заселение за отзыв
    - Свой вариант
11. Если есть условие скидки — опишите точно (от скольки ночей, сколько %). — **[абзац, необязательно]**

### Раздел 5. Заезд и выезд
12. Время заезда? — **[текст]** (например: «с 15:00»)
13. Время выезда? — **[текст]** (например: «до 12:00»)
14. Возможен ли ранний заезд / поздний выезд? На каких условиях? — **[абзац, необязательно]**

### Раздел 6. Правила объекта
15. Можно ли с животными? — **[выбор]** Да / Нет / По согласованию
16. Можно ли курить? — **[выбор]** Да / Нет / Только на балконе
17. Есть ли депозит? Сколько и когда возвращается? — **[текст, необязательно]**
18. Максимальное число гостей? — **[текст]**
19. Другие важные правила (тихий час, нельзя вечеринки и т.п.)? — **[абзац, необязательно]**

### Раздел 7. Частые вопросы под этот объект
20. Парковка: есть ли, бесплатная/платная, где? — **[абзац, необязательно]**
21. Что рядом (метро, магазины, центр)? — **[абзац, необязательно]**
22. Особенности квартиры, которые часто спрашивают (вид, этаж, техника, бытовое)? — **[абзац, необязательно]**
23. Любые ситуации, на которые бот должен отвечать определённым образом? — **[абзац, необязательно]**

---

## B. Данные объекта (идут в поля Property, НЕ в текст промпта!)

> ⚠️ Эти данные бот выдаёт гостю ТОЛЬКО после оплаты и заезда (гейтинг по фазе).
> Поэтому их заводим в отдельные поля карточки объекта, а не в свободный текст —
> иначе защита не сработает.

24. Точный адрес объекта — **[текст]** → `Property.address`
25. Короткое описание объекта для гостя — **[абзац]** → `Property.description`
26. Код от двери / подъезда — **[текст]** → `Property.doorCode`
27. Название WiFi-сети — **[текст]** → `Property.wifiName`
28. Пароль от WiFi — **[текст]** → `Property.wifiPassword`
29. Инструкция по заселению (как попасть, где ключи, нюансы) — **[абзац]** → `Property.checkInInstructions`

## C. Промпт сборки для ИИ (вставлять в ChatGPT вместе с ответами клиента)

```
Ты — помощник, который превращает анкету владельца квартиры посуточной аренды
в краткую инструкцию для чат-бота (поле customPrompt).

ВАЖНО ПРО КОНТЕКСТ:
У бота уже есть постоянный базовый промпт, который задаёт: общение только на
русском, короткие ответы 1-2 предложения без эмодзи и markdown, все правила
площадки Авито (не давать телефоны/мессенджеры/ссылки, оплата только через Авито),
механику FAQ и эскалацию оператору. ЭТО ПОВТОРЯТЬ НЕ НАДО — оно уже есть.

ТВОЯ ЗАДАЧА:
Из ответов анкеты собери ТОЛЬКО бизнес-специфику этого объекта в виде понятных
ИИ-боту инструкций. Структура разделами (заголовок капсом, под ним правила):
ТОН / БРОНИРОВАНИЕ / ОТМЕНА И ВОЗВРАТ / ЦЕНА И ТОРГ / ЗАЕЗД-ВЫЕЗД / ПРАВИЛА ОБЪЕКТА /
ЧАСТЫЕ ВОПРОСЫ.

ПРАВИЛА:
- Пиши конкретно и кратко, как инструкции, а не как маркетинг.
- Где у бота есть готовая фраза для гостя — давай её в кавычках «...».
- НЕ добавляй разделы, по которым клиент ничего не указал (пропускай пустое).
- НЕ дублируй правила Авито, формат ответа, запрет эмодзи — это в базовом.
- НЕ вставляй сюда код двери, wifi, адрес, инструкцию заезда — они в полях объекта.
- Общий объём — до 1500 символов. Только русский.

ФОРМАТ ВЫВОДА: только готовый текст customPrompt, без пояснений.

АНКЕТА КЛИЕНТА:
[сюда вставить ответы из Google-формы, раздел A]
```

## D. Эталонный пример (для калибровки ИИ — можно дать как образец)

> Пример того, как должен выглядеть готовый customPrompt после сборки. Показывает
> ИИ нужный уровень детализации и формат. Совпадает по структуре с шаблоном-рыбой
> в `server/services/promptTemplate.ts`.

```
ТОН: дружелюбный, спокойный, на «вы». Отвечай как заботливый хозяин.

БРОНИРОВАНИЕ:
При желании забронировать: «Для подтверждения брони нужна предоплата через Авито. Как только оплата поступит — даты закреплю за вами.»

ОТМЕНА И ВОЗВРАТ:
Больше 7 дней до заезда — отмена бесплатная, деньги вернутся за 5 рабочих дней через Авито.
Меньше 7 дней или в день заезда — предоплата не возвращается.

ЦЕНА И ТОРГ:
Цену напрямую не снижай. При просьбе о скидке: «Можем предложить скидку на следующее заселение за отзыв после проживания.»

ЗАЕЗД / ВЫЕЗД:
Заезд с 15:00, выезд до 12:00. Ранний заезд по возможности, уточняйте за день.

ПРАВИЛА ОБЪЕКТА:
С животными нельзя. Курение запрещено. Максимум 4 гостя. Тихий час после 23:00.

ЧАСТЫЕ ВОПРОСЫ:
Парковка во дворе бесплатная. До метро 7 минут пешком.
```
